Important definition:
Completed outgoing calls means the team member reached the patient and discussed with them.
It does not mean total call attempts.
Voicemails, no answer, missed calls, and failed attempts do not count as completed outgoing calls.

Use these example calculations:
- 100% workday = 30 completed calls
- 50% workday = 15 completed calls
- 25% workday = 7 completed calls
- 0% workday = 0 completed calls
- minimum patients scheduled = 50% of completed call KPI

PART 5 — Distribution engine

Add or improve distribution logic.

Distribution must consider:
- available repository patients
- facility coverage
- platform calendar working status
- TeamOps staffing/PTO/coverage status if available
- admin manual workingToday override
- call workday percentage
- completed call KPI
- visit/outreach mix
- current active incomplete carryover
- current assigned active calls
- calls completed today
- scheduled-patient KPI
- priority
- cooldown eligibility
- whether patient has required PDFs/proof if required
- role/team suitability: PCS vs ACS if available

Critical rule:
Do not assign a team member more new calls than their remaining capacity after carryover.

Formula:
daily assignment capacity
minus active incomplete carryover
equals new assignment capacity

Example:
Target 30 calls
12 incomplete carryover
New assignment capacity = 18

Do not blindly assign 30 new calls to someone who already has 12 incomplete calls.

PART 6 — Carryover logic

Incomplete calls from prior days should count against today’s capacity.

Carryover should include assigned cases that are:
- not completed
- not declined/finalized
- still needing call/follow-up/scheduling
- assigned to that team member
- due before today or created before today if still open

Carryover should not include:
- completed cases
- scheduled/finalized cases if no call action remains
- declined/closed cases
- transferred/reassigned cases

Show carryover count in Call Settings and live metrics.
