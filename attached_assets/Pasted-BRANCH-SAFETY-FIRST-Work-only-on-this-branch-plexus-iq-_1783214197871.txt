PART 4 — Report upload trigger

5. Trigger documentation reconciliation.
6. Trigger Clinical Intelligence result review.
7. Create or update repeat eligibility opportunity if medically supported and data is available.
8. Write patient_journey_events if existing event infrastructure supports it.

Report upload should be a catch-all safety trigger.

Correct timeline:
- Order note should normally be generated when patient is scheduled.
- Procedure note should normally be generated when report is uploaded.

- Report upload is a safety reconciliation point.

PART 7 — Repeat eligibility logic for current workflow

This is required for the current BrainWave/VitalWave/Ultrasound business workflow.

When a BrainWave/VitalWave/Ultrasound report is uploaded:

1. Clinical Intelligence reviews report.
2. Extract prior findings and possible ICD opportunities if supported.
3. Determine payer type if available.
4. Calculate repeat interval:
   - PPO/commercial: 6 months if medically supported
   - Medicare: 12 months if medically supported
5. Calculate repeat due date.
6. Calculate Admin Review open date:
   - default: 1 month before repeat due date
7. Create Repeat Eligibility item / Repeat Opportunity.
8. Do NOT immediately send to Engagement unless the repeat is due now and Admin approved.
9. Store/derive cooldown state until due/review date.
10. Route to Plexus IQ Repeat Testing Review when admin review date arrives.

PART 12 — Scheduling reconciliation

This is required.

Before any repeat-test email, text, or call-list placement, the system must check whether the patient is already scheduled.

Check scheduling status by:

- patientId
- ancillary/test type
- repeat due window
- scheduled appointment date
- appointment status
- execution case linkage if available

Possible scheduling states:

- Not Scheduled
- Already Scheduled
- Scheduled Online
- Scheduled by Team
- Cancelled
- Missed
- Needs Reschedule
- Completed

Rules:

1. If already scheduled:
   - Do not send unnecessary outreach.
   - Do not add to active call list unless confirmation/reschedule is needed.
   - Status trail:
     Plexus IQ Repeat Approved → Scheduling Reconciled → Already Scheduled

2. If not scheduled:
   - Start Engagement outreach sequence.
   - Status trail:
     Plexus IQ Repeat Approved → Scheduling Reconciled → Not Scheduled → Email Pending

3. If patient schedules online after email/text:
   - Stop remaining outreach steps.
   - Do not send the text/call if already scheduled.
   - Status trail:
     Plexus IQ Repeat Approved → Email Sent → Patient Scheduled Online → Outreach Complete

4. If cancelled:
   - Move back to Engagement as Needs Reschedule.
   - Call Type can be:
     Reschedule Missed Test
     or Repeat Test Due depending on context.

5. If missed:
   - Move back to Engagement as Reschedule Missed Test.

Before every outreach step:
- re-check schedule status
- stop outreach if scheduled
