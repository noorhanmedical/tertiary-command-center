TASK:

Reimagine and redesign TeamOps as a premium calendar-first staffing, PTO, coverage, and technician scheduling command center.

Current problem:
TeamOps currently feels disjointed and low-quality. It has tabs like:
- Dashboard
- Staffing Calendar
- PTO Coverage Assignments
- Schedule Technician Schedule

But there is no real calendar-first experience. That makes no sense. If this page is about schedules, staffing, PTO, and technicians, then the calendar must be central.

Goal:
Make TeamOps feel like a premium iOS-style staffing and clinic operations scheduler. The product should be intuitive, calendar-first, visually polished, and useful for admins/managers.

Core purpose:
TeamOps should answer:
- Who is working today?
- Who is off/PTO?
- Who needs coverage?
- Which clinic is short?
- Which technician is assigned where?
- Are there schedule conflicts?
- Which clinics/services are at risk because of staffing gaps?
- What coverage assignments need action?

Architecture rules:
- TeamOps is for staffing, PTO, coverage, and technician scheduling.
- Mission Control is top-level operational oversight.
- Engagement Center assigns patient outreach/call work.
- Team Member Portal is where ACS/PCS work call lists.
- Do not move call-list work into TeamOps.
- Do not use old Outreach Center.
- Do not use /api/scheduler-assignments for Engagement Center-assigned call work.
- Do not change database schema unless absolutely required.
- Use existing team/roster/schedule/PTO data sources where available.
- Do not invent fake data.
- Use graceful empty states if data is not wired yet.

Do not keep disconnected tabs that show unrelated tables with no calendar.

- clinic/facility filter

PART 4 — Calendar-first workspace

Create a main TeamOps calendar workspace.

Calendar requirements:
- Support Day / Week / Month view if feasible.
- Show staff shifts as calendar blocks.
- Show PTO/time-off as calendar blocks.
- Show technician assignments as calendar blocks.
- Show coverage gaps as visible warning blocks.
- Show clinic/facility label on each assignment if available.
- Show role label: PCS, ACS, Technician, Manager, Billing, Scheduler, Liaison, etc.
- Allow selecting a date/day/block.
- Selected day/block opens a right-side detail panel.

If real schedule data is not available yet:
- build the calendar structure with honest empty states
- do not fake staff assignments
- show “No staffing assignments available from connected sources yet.”
