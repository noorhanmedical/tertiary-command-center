Current problem:
In the Team Member Portal top banner, admin sees a dropdown that says “Admin,” but when clicked it does not show team members. I need this dropdown to show actual ACS/PCS team members so admin can select a person and see that person’s assigned call list.

This is not just a label change. Wire the dropdown to the real team-member roster and use the selected team member to reload the right-panel call list.

Architecture rules:
- Team Member Portal is the canonical destination for call-list work.
- Engagement Center assigns work.
- patient_execution_cases is the source of truth for assigned call work.
- The current active Team Portal Call List endpoint is /api/scheduler-portal/cases, which projects patient_execution_cases.
- Team-member roster currently appears to be backed by /api/outreach/schedulers. Despite the legacy name, this roster endpoint is canonical and should remain available.
- /api/scheduler-assignments is legacy/compatibility only and must not be used for Engagement Center-assigned call work.
- Do not route users to old Outreach Center or scheduler pages.
- Do not change database schema unless absolutely required.
